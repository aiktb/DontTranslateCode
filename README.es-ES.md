# No traducir código

El traductor web ya no traducirá los bloques de código en las páginas, y ya no hará que la fuente del código se vea extraña.

Un agradecimiento especial a **_[plasmo](https://github.com/PlasmoHQ/plasmo)_** por eliminar la frustración del desarrollo de extensiones de navegador para mí.

![Principio](https://s2.loli.net/2023/10/14/R2VUykeXCA8iTFG.webp)

## Características

- [x] Evita que el traductor traduzca los elementos `pre`.
- [x] Fuerza la fuente de los elementos `code` y `pre` a `Intel One Mono`.

## Contribución

Asegúrate de leer la [Guía de Contribución](./.github/CONTRIBUTING.md) antes de crear un pull request.

Esto incluye instrucciones sobre cómo configurar el entorno de desarrollo, probar extensiones y compilar el producto final.
